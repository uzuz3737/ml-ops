## Approved retraining snapshots

Configure `dataset.retraining_snapshots` in project.yaml as a map from candidate_dataset_version to a project-relative `{uri, sha256}` JSON manifest reference. P0 controller approval and frozen config digest select that version. Manifest requires contract_version 1, matching dataset_version, schema_version credit-default-v1, nonempty source/license/attribution, partitions containing exactly train and validation references, and protected_ids referencing a nonempty JSON list of original final-test IDs. Each reference includes uri and SHA-256. Partition files contain canonical JSON records with ID and label. Both classes must occur in each partition. IDs must be unique and disjoint from each other and protected holdout. Checksums are checked before parsing; changed/unapproved snapshots fail closed.

The adapter retains the preapproved partition membership instead of randomly resplitting it. Retraining split output contains only train and validation, with strategy approved-independent-snapshot; it never exposes final_test or monitoring for retraining consumers. P2 must use those partitions for current-regime evaluation. Snapshot protected_ids must equal dataset.protected_final_test_ids in the frozen project config. Reviewers pin the actual original final-test ID manifest there; candidates cannot substitute their own protected list. The adapter checks overlaps but cannot infer IDs omitted from the original trusted list.

## Empirical feature-drift calibration

`calibrate_threshold(train, window_rows=..., trials=100, quantile=0.99, seed=42)` estimates the maximum-feature PSI null distribution by bootstrapping windows from train only. It returns the threshold and all null scores with method, seed, sample/trial counts and scope. This incorporates multiple-feature testing into the demo threshold; it does not guarantee a production false-alarm rate. Never fit thresholds on monitoring or final test. Use the same window size in calibration and monitoring.

Real-UCI CI now persists calibration, healthy replay and synthetic-shift reports. A local source measurement using 18,000 training rows and 3,000 replay rows produced a threshold 0.01248, healthy maximum PSI 0.00823 (no alert), and shifted maximum PSI 9.62215 (alert). Bootstrap values depend on reference ordering; retain actual run artifacts rather than treating these example values as operational constants. Docker CI additionally executes P0's subprocess runner ingest/validate/split/features as the default app user.
